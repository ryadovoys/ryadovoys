# Sergey Ryadovoy

Product designer in San Jose. I build small tools for my own work and share the ones that turned out useful.

More at [ryadovoy.com](https://www.ryadovoy.com).

## Tools

- [dictator](https://github.com/ryadovoys/dictator): local dictation for Mac, nothing leaves your computer
- [skaz](https://github.com/ryadovoys/skaz): voice and clipboard screenshots merged into one Markdown file
- [resume.md](https://github.com/ryadovoys/resume.md): a Markdown format for resumes
- [mindcomplete](https://github.com/ryadovoys/mindcomplete): AI writing assistant that completes your thoughts

## Skills

AI skills for Claude Code, Cursor and Codex. Install all of them with `npx skills add ryadovoys/skills`.

- [sergey-design-skill](https://github.com/ryadovoys/skills/tree/main/skills/sergey-design-skill): calm, product-grade pages in the style of [audit.ryadovoy.com](https://audit.ryadovoy.com)
- [sergey-questionnaire-design](https://github.com/ryadovoys/skills/tree/main/skills/sergey-questionnaire-design): a questionnaire where the answers write a letter, with an optional price estimate
